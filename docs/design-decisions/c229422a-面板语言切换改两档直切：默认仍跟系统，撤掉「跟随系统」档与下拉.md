# c229422a. 面板语言切换改两档直切：默认仍跟系统，撤掉「跟随系统」档与下拉

- **日期：** 2026-10-26
- **状态：** 已采纳
- **影响范围：** `ui/components`（`LocaleSwitch`）、`shared/dicts/i18n`（删 3 个键）、`tests/i18n.test.ts`
- **相关记录：** 沿 0016（i18n 键化 + 默认语言取系统语言 + 手动切换）；只改选择器形状，locale 优先序与持久化不动。0037 的 tooltip 口径随之少一个消费点（语言提示气泡撤掉）

## 压力

0016 落地的面板选择器是三档下拉（`跟随系统 / 中文 / English`）。三档里「跟随系统」与「没选过」是同一个状态 —— `choice` 的初值就是 `SYSTEM_CHOICE`，`resolveUiLocale` 对二者都走 `navigator.language`。把两个等价态并排摆进下拉，等于让用户在一个假分叉上做选择。

第二重压力来自位置：语言早已收进页头二级菜单（`OverflowMenu`），在菜单里再展开一层浮层要管遮罩、Escape、焦点归还（0014 的高度口径也靠浮层不进文档流兜着），而这层浮层换来的只是「在中文 / English 之间选一个」。

用户 2026-10-26 的定案：不要下拉，面板上就是 ZH / EN 两档互切，默认值按系统语言。

## 候选与排除

| 候选 | 结论 | 排除理由 |
|---|---|---|
| 两档直切（`中` / `EN`），`choice` 初值仍是 `SYSTEM_CHOICE` | 采用 | 默认态本身就是「跟随系统」，无需第三档；两档常驻、点即切，少一次展开交互；与 website 页头的语言二选一同形 |
| 保留三档下拉 | 排除 | 「跟随系统」与「没选过」等价，是假分叉；下拉在二级菜单里再套浮层，收益不抵成本 |
| 单按钮切换（按钮上显示「会切到的那一档」，同 `ThemeToggle`） | 排除 | 主题两档在图标上对称可辨，语言不对称：按钮只写一个语种时，用户容易把它读成「当前语言」而不是「点它会切到」。两档摊开没有这个歧义 |
| 保留「跟随系统」为第三档（下拉改三连按钮） | 排除 | 需求明确只要 ZH / EN 互切；要回退跟随系统属新需求，命中本记录退出条件再开 |
| 保持简单：不动，继续用下拉 | 排除 | 需求已点名要改；且两档直切确实是更少的代码（少一层浮层与状态机） |

## 结论

面板语言选择器改为**两档直切**：`中` / `EN` 两颗按钮，`aria-pressed` 标当前生效档，点另一档即切。

- **默认值仍来自系统语言**：`choice` 初值仍是 `SYSTEM_CHOICE`，`locale()` = `resolveUiLocale({ stored: choice(), navigatorLanguage })`，优先序（用户选择 > `navigator.language` > 兜底 `en`）与持久化协议（`locale_set` / `locale_state`）**一行不改**。变的只是「用户能选哪几档」。
- **「跟随系统」不再是可点档位**，但仍是**默认态**：没选过就跟着系统走。
- 点当前档不写存储：没有变化就不产生一条「显式选择」。

## 实施方案

- **目标形状**：`packages/ui/src/components/LocaleSwitch.tsx` 重写为 `role="group"` + `For each={LOCALES}` 的两颗按钮，aria-label 用全名（`locale.zh-CN` / `locale.en`），上屏缩写（`locale.abbr.*`）。不再有 `open` 信号、遮罩、Escape 转发、Tooltip。
- **数据层**：`LocaleChoice` / `SYSTEM_CHOICE` / `resolveUiLocale` / `toStoredChoice` / `useLocale` 状态机与消息契约全部不动 —— `system` 仍是合法取值（默认态与历史存储值都可能是它）。只删掉 UI 侧已无消费方的 `systemLocale` 导出（它只服务旧 tooltip 的「当前落点」）。
- **文案表**：删 3 个只服务旧形状的键 —— `locale.system`（档位名）、`locale.title.followSystem`（tooltip）、`locale.title.fixed`（tooltip）；zh / en 两份同步删。`locale.menu` 仍作 group 的 aria-label，`locale.zh-CN` / `locale.en` / `locale.abbr.*` 保留。
- **本次不做**：不提供「改回跟随系统」的入口；不给两档加 tooltip（二级菜单行已有「语言」标签，全名在 aria-label）。

## 成本与退出条件

- 成本：用户一旦点过就固定在显式选择上，面板内没有回到「跟随系统」的路（要清 `clientStorage` 或换设备）。
- 退出条件：若重新要求「可切回跟随系统」→ 恢复第三档或另加一个重置项；届时优先加按钮而不是退回下拉（浮层那套成本不划算）。
