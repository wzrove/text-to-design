# 420facdc. 默认精简 MCP 目录并统一画布批处理

- **日期：** 2026-11-19
- **状态：** 已采纳
- **影响范围：** `shared/dicts`、`mcp-server`
- **相关记录：** 取代 3f364c28

## 压力

默认兼容档发布 59 个工具。旧精简档仍发布 27 个，大量绘制 schema 常驻，模型也可逐项直调。用户明确要求缩小默认目录，并让绘制优先批处理。

## 候选与排除

| 候选 | 结论 | 排除理由 |
|---|---|---|
| 复用公开目录投影、能力查询和批处理 | 采用 | 注册表已有独立的公开与执行路径 |
| 直接启用原精简清单 | 排除 | 常用绘制工具仍直接可调，且重复发布输入 schema |
| 合并各操作的参数 schema | 排除 | 跨操作参数仍须发布，增加校验分流 |

## 结论

默认 compact 公开 11 个入口。创建、属性、结构、组件和平台操作继续使用原能力定义，经 jsd_batch 执行。full 显式启用时继续公开 59 个入口。

## 实施方案

- 默认目录直出连接、读取、节点引用、导出、配方和编排入口。保留两个配方工具，供只有 tools 接口的宿主在首次写入前读取指引。
- 确认步骤名称后按需取 schema，再按语义块顺序执行，单项操作也可走单步批。复用参数校验、平台门控和漂移检查。
- 回显裁剪时指向独立读取入口或落盘明细，避免要求重放写入。

## 成本与退出条件

- 首次使用每类写操作需按需查 schema。直调集成可设置 `TEXT_TO_DESIGN_TOOL_PROFILE=full`，重启 daemon 并重连。
- 若实际任务中同一操作反复触发发现，按发现次数、误选率和任务完成率复审公开清单。

## 验证
