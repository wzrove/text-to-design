# 批量改文案

默认精简档把本配方的绘制与编辑操作放入 `jsd_batch`，工具名填 `calls[].tool`；用 `jsd_describe_tools` 的 names 查步骤参数。

用于指定子树或选区中的文本替换。多步编排见 [批量编排](script-ops.md)。通用失败处置与视觉验收按主技能「执行闭环」。

## 建立替换映射

1. 用户指定 id 时按 id 用 `jsd_find`；用户指当前选中时先 `jsd_get_selection` 确认根。
2. 读取目标子树的 TEXT、characters 与所属分区，生成“节点 id → 原文 → 新文”映射。只改指定范围；同名文本不能仅凭名字认定为同一用途。
3. 保留原文与受改属性，供定向恢复。需要对照稿或改动范围大时可复制目标块并记录副本 id；不默认复制整页或删除用户已有备份。

## 应用

- `jsd_set_text` 单次的 characters 与排版参数应用于 ids 中全部节点。只有新文相同才合并 ids；不同文案拆成多个 `jsd_batch` 步骤，不能传逐节点文案数组。
- 先保留现有字号与布局。固定宽的自动换行文本传 width + `textAutoResize:"HEIGHT"`；仅在新文导致溢出且任务允许时调整容器或排版。
- 实例中的文案先查组件属性及可见图层映射。全局文案改主件；局部文案优先用 `jsd_set_instance_properties` 写对应实例属性，避免无意影响其他实例。

## 特有错误、核对与恢复

- 目标 id 未命中、节点类型不是 TEXT 或 subtree 读取被截断：列出未命中项并暂停对应替换，不用名称近似匹配。
- warnings 报字段未生效、`applied[].ok === false` 或超时：先 `jsd_find` 回读当前块，只补失败项；不重放整批替换。
- 新文导致换行、裁切、行高或间距异常时，用 `jsd_export` 检查受影响块，再按任务范围调整排版或恢复原文。
- 收尾独立回读 characters，与映射逐项核对；报告实际改动范围、未命中项与未验证项。仅清理本任务创建且不再需要的临时副本，恢复时使用保存的原文，不凭记忆重写。
