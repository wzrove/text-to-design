# 自动布局

默认精简档把本配方的绘制与编辑操作放入 `jsd_batch`，工具名填 `calls[].tool`；用 `jsd_describe_tools` 的 names 查步骤参数。

通用失败处置按主技能「执行闭环」。批次清单优先用服务端可读的 `callsFile`，其余情况用内联 `calls`，见 [批量编排](script-ops.md)。

## 建层前确定布局行为

每个容器先回答三件事：直属子项沿哪个方向排列，宽和高分别由谁决定，内容变长或父容器变窄时哪里换行、哪里增高、哪里保持完整。把决定落实到容器层级和对应轴的属性。

| 内容 | 设置 |
| --- | --- |
| 导航、标签、筛选项、按钮组 | `HORIZONTAL`，固定 `itemSpacing`，需要垂直居中时设交叉轴 `CENTER` |
| 列表、表单、页面分区 | 外层 `VERTICAL`，每行独立 FRAME，行内再按直属子项定方向 |
| 多列卡片或异构分区 | 嵌套显式行列容器。外层排区块，内层按阅读顺序排图片、文字和操作 |
| 浮层、重叠装饰、坐标型绘图区 | 置于 `NONE` 子容器，整块作为外层布局的一个子项 |

- 用 `paddingTop`、`paddingRight`、`paddingBottom`、`paddingLeft` 管四边内距，用 `itemSpacing` 管直属子项之间的固定间距。优先复用当前稿的间距值。遇到两种间距，把同组元素包成子容器。
- 容器布局字段适用于 FRAME、COMPONENT、COMPONENT_SET。需要新包一层时优先用 FRAME。当前共享工具 schema 无换行、布局内绝对定位字段；多行显式分行，浮层用自由定位容器。

## 尺寸按轴声明

主轴由 `layoutMode` 决定。`HORIZONTAL` 的主轴是宽，`VERTICAL` 的主轴是高。

| 目标 | 尺寸模式 |
| --- | --- |
| 固定宽、内容决定高的纵向卡片 | primaryAxisSizingMode=AUTO、counterAxisSizingMode=FIXED + width |
| 固定宽、内容决定高的横向行 | primaryAxisSizingMode=FIXED、counterAxisSizingMode=AUTO + width |
| 屏根、固定栅格或明确尺寸的容器 | 两轴 FIXED + width/height |
| 内容决定宽的横向标签组 | 主轴 AUTO，交叉轴按目标高度选择 |

- `AUTO` 表示该容器由内容决定尺寸。可增长的内层高度优先 AUTO；屏根、固定槽位或确有规格的轴显式设 FIXED，并给实际尺寸。
- 子项用 `layoutGrow:1` 接收父主轴的剩余空间，用 `layoutAlign:"STRETCH"` 撑满父交叉轴。先给对应的父轴明确边界，避免父级随内容增长、子级同时要求填满同一轴。三平台的 `layoutGrow` 都只用 `0` 或 `1`。
- 等宽和等距分别回读。固定规格的等分宽度为「扣除内边距后的有效宽度减去间距总和，再除以列数」。遇到小数像素，检查末项右边界和各项中心。若固定整数像素，分散分配余量，让各列总宽加间距恰好等于有效宽度。

## 常见结构

| 场景 | 规则 |
| --- | --- |
| 可变文案 + 操作区 | 操作区按内容和内边距取宽，信息区用 `layoutGrow:1` 接收剩余宽度。可换行的文本用有边界的宽度和 `textAutoResize:"HEIGHT"`，上层允许增高。变窄后仍放不下时，按目标宽度改为上下排列。 |
| 重复行和卡片 | 先确定共享的对齐线。横向卡片保留固定图槽，信息列填剩余宽度，价格行沿信息列交叉轴 `STRETCH`，按钮贴右内边距。纵向列表让各行撑满有效宽度，再在行内分配剩余空间。需要卡片底部齐平时，预留统一的标题空间，用长短两种内容验证底部操作位。 |
| 后补 SVG、图片或角标 | 先定父级。导航用一个 FRAME 包住图标和标签，复用已有定宽定高槽位并让图标两轴居中。媒体和叠放角标放进独立的自由定位 FRAME，再让整块参与外层布局。移入后回读父级与坐标；换图再查裁切、圆角及 `z` 层序。 |
| 固定视窗或长页页脚 | 区块间距用 `itemSpacing`。页脚跟随内容时放在纵向流末尾；长页可让内容区和画板都随内容增高。固定视窗需要贴底时，用有明确高度的父容器分配剩余空间，超高内容按规格放入独立滚动区或重排。 |

- **两端对齐**：平台支持时，`SPACE_BETWEEN` 在有明确宽度的行里分配空余空间，此时 `itemSpacing` 不生效。子项总宽超限时，调整宽度或重排。
- **平台差异**：即时设计、MasterGo 的子项 `layoutAlign` 用 `INHERIT` 或 `STRETCH`，单项对齐可用带明确尺寸的内层 FRAME。MasterGo 主轴对齐用 `MIN` 或 `CENTER`，交叉轴避免 `MAX`。两端对齐可用上表的信息区伸展方式。
- **已有图标槽**：在同一批用 `jsd_create_icon` 创建，再用 `jsd_reparent_nodes` 按返回 id 移入。验收时确认图标居中，选中态与未选中态仍可区分。

## 执行顺序

1. **读现状。** 用 `jsd_find` 读取目标和父级，记录容器宽高、方向、尺寸模式，以及直属子项的 id、位置、尺寸和顺序。只改已有布局的间距或对齐时，只写对应字段。
2. **先做样板。** 转换已有稿时挑一个代表行或卡片，记录左边缘、对齐线、内边距和按钮位置。对无旋转的规整子项，用「后一项起点减前一项终点」量实际间距。间距不一致时先找语义分组，重叠项留在自由定位子容器。样板先按原尺寸与改前截图比对，再用较长文案验证；两轮通过后再推广。
3. **先层级，再开布局。** 小型新建子树可在创建时一次声明完整布局。复杂树先建容器与子项，用 `jsd_reparent_nodes` 显式传 `parentId`，需要重排时传 `index`；结构就位后从内层向外层设置布局。父布局已开启后，再对子项设置 grow 或 stretch。相依步骤留在同一批。
4. **明确固定轴。** 启用布局或换方向时，用 `jsd_set_layout` 在同一步声明目标方向与两轴模式。确需改变宽高时用 `jsd_resize_node`；有混合 FIXED/AUTO 轴时，只写需修的尺寸，再回读模式和宽高。
5. **验收通过再推广或交付。** 先查布局和移父步骤的 warnings，再按下方验收项检查。

## 排查与修复

| 现象 | 排查与修复 |
| --- | --- |
| 子项被裁切、坐标为负 | 逐层读取子项和父级。横向检查 `x`、`x + width`，纵向检查 `y`、`y + height`。将实际边界与父尺寸及预期内边距比较，再检查子项尺寸总和、间距和内边距是否放得下。 |
| 子项移动后位置回弹 | 布局接管坐标。用 `jsd_reparent_nodes` 的 `index` 调顺序，用容器的间距、内边距或对齐字段调位置。移父后按 warnings 和回读补写被改动的属性。 |
| 开布局后尺寸变化 | 先区分 FIXED 与 AUTO 轴。只有固定轴偏离目标才用 `jsd_resize_node` 单独修正该轴，并再次回读两轴模式。 |
| 文本变窄、缺字或不可见 | 查父级有效宽度、文本框宽高和 `textAutoResize`。导出发现装饰符号缺字时，用可用图标或保留文字标签。即时设计绑定 TEXT 样式后的零宽修复见 [设计策略](design-strategy.md)。 |
| 某字段未生效 | 查 warnings 和当前平台支持范围。换受支持的布局结构，再回读验证。网格用 `layoutGrids`，当前引擎仅在非自动布局容器收网格；MasterGo 节点级写入未落盘时，报告需在设计器处理。 |

## 验收

视觉和布局两项都要通过。

- **布局**：用 `jsd_find({ids:[容器id], depth:1})` 回读父子关系、实际宽高、尺寸模式、顺序、间距和内边距。嵌套层按 id 补读。固定轴符合目标，AUTO 轴容纳内容。
- **视觉**：用 `jsd_export` 按原尺寸检查对齐、遮挡、裁切和文字可见性。仅补布局语义时，与原稿比对关键位置和尺寸。
- **自适应**：在副本上用目标范围内较窄的宽度和一组较长的真实文案组合验证。检查文字换行、操作按钮可见、卡片能增高；有等宽列或页脚时，复核边界与位置。

## 示例：定宽、随内容增高的卡片头

先回读横行及两个直属子项，确认顺序为标题区、操作区，且操作区按内容定宽。用真实 id 替换示例中的 `12:1` 和 `12:2`。两步在同一批执行，横行保留当前宽度，标题区占剩余宽度，整体高度随内容增长。

```json
{
  "calls": [
    {
      "id": "row",
      "tool": "jsd_set_layout",
      "args": {
        "ids": ["12:1"],
        "layoutMode": "HORIZONTAL",
        "primaryAxisSizingMode": "FIXED",
        "counterAxisSizingMode": "AUTO",
        "primaryAxisAlignItems": "MIN",
        "counterAxisAlignItems": "CENTER",
        "itemSpacing": 12
      }
    },
    {
      "id": "title-fill",
      "tool": "jsd_set_layout",
      "args": { "ids": ["12:2"], "layoutGrow": 1 }
    }
  ]
}
```
