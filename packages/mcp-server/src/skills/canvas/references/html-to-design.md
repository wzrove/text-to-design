# HTML 转设计稿

输入为用户提供的 HTML，输出为设计节点。转换器不执行页面脚本，也不具备浏览器完整 CSS 布局能力。

## 默认路径

用户仅需静态转换、无需逐元素编辑时，用 `jsd_html_to_design({html:用户HTML, name:语义名称})`。当前实现解析 HTML 与有限的内联样式，生成 SVG 后导入；不会使用外部样式表或 style 标签，复杂 CSS 不能保证还原。

不要把它描述为浏览器截图或像素级保真。需要准确复刻复杂页面时，先依据用户已有参考和布局需求确定可表达结构。

## 需要可编辑图层时

按 [设计策略](design-strategy.md) 与 [自动布局](auto-layout.md) 映射原生结构：

| HTML 内容 | 节点 |
| --- | --- |
| section、卡片、布局容器 | FRAME |
| 标题、正文、按钮文案 | TEXT |
| 图标、SVG 几何 | jsd_create_icon 或 SVG 导入 |
| 图片 | 对应形状节点 + jsd_fill_image |

保留语义名称与分区层级，尺寸按设计 px 映射；行列改用布局字段，不能把 CSS auto 原样交给画布。已有组件或样式命中时复用。批量建节点后逐层归组，避免所有元素落在页面顶层。

## 装配与验收

从 created.id 取得转换结果，需放进已有画板时显式 reparent；落位再用 move/resize，不能给 SVG 转换入口附加不支持的 placement。

导出检查文字、尺寸、裁切、间距与未还原样式。需要可编辑时同时回读层级和 TEXT，向用户说明保留为矢量或未还原的部分。
