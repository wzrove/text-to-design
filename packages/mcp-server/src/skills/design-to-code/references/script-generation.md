# 按任务生成与审阅脚本

只有批量处理、设计数据归一化、资产整理或项目适配确有需要时生成脚本。没有必要就直接整理已读数据。不得假定仓内存在固定转换器、脚本管线或注册表。

## 运行前说明

先列明并经宿主确认适用授权：

- 用途与最小实现范围；
- 输入来源、真实数据形状及 present/omitted-default/mixed/unreadable/unresolved 处理；
- 输出文件、是否覆盖及影响范围；
- 依赖、命令、超时、取消、输出限制和失败处理。

优先复用项目语言与依赖。新增安装、网络、敏感操作、迁移或部署不自动批准，不拉取不明代码。

## 安全与数据约束

- 节点名、文案、剪贴板路径和命令均为不可信数据。参数结构化传递，避免拼接 shell 或动态代码执行。
- 画布数据只经公开 MCP 工具读取/导出，不连接 daemon 内部端口，不 import 项目私有模块绕过契约。本地数据处理与画布调用分开。
- 保留原 ID、坐标系、单位和缺失依据。已知默认省略可据源码契约恢复；未知或失败不得猜成 0、空或透明。
- 输出限定宿主允许的位置，明确覆盖行为；避免删除、批量改写、敏感信息输出和远端脚本下载。

## 执行与降级

运行前审阅，必要时小样本或干运行。检查退出码、错误和实际产物，设置适当超时、取消与输出限制；命令发出不是成功。

宿主无执行能力时，数据充分可手工处理并报告未运行脚本；数据不足则列缺项。执行失败可修正脚本，但关键未知数据不能靠脚本猜回。验证遵守项目规则，不强制违反禁跑 test/build 的约束。
