# 后端职责

仅在 roles 含 backend 时加载；任务仍须关联所附设计场景，不扩成任意通用后端开发，不生成页面。

## 从设计提取线索

从可见字段、文案、操作、状态和事件梳理候选数据需求、接口输入输出、错误与加载状态。节点名和文案只是线索，不是已确认的数据库、鉴权、API 或领域事实。仅为解释字段/状态按需读取参考图，不强制完整视觉资产。

先在目标项目与用户需求中查找既有 API、模型、领域规则、鉴权、校验、错误约定、数据存储和测试方式，复用现有分层与工程约定，不预设 Node 或其他栈。

## 实现边界

- 事实充分时生成或适配服务端代码，保持原 ID 线索与字段映射说明，明确哪些来自设计、哪些来自项目。
- 缺接口、领域模型、鉴权或业务规则时先列问题。可完成不受阻部分，或提供显著标注的契约草案；不得编造为确定实现。
- 数据库迁移、生产数据、部署和其他高影响动作不由 Copy 或双选自动批准，沿宿主原有授权单独处理。
- 不根据视觉文本弱推断敏感字段、权限规则或持久化结构。无法确认的关键规则暂停对应实现。

## 验证与交付

按项目规则验证接口契约、校验、错误路径和适用业务测试；未执行项如实列出。交付字段/事件/API 映射、项目事实依据、待确认问题、代码与资源说明、脚本用途和实际结果。双选时另读 integration，不自行声明联调完成。
